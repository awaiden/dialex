# h3 / Nitro

h3 1.x sunucuları için: Nitro 2 ile Nuxt sunucu rotaları ve middleware'i.

```ts
// server/middleware/dialex.ts (Nuxt / Nitro)
import { dialexH3 } from "dialexjs/h3";

import { dialex } from "~/dialex.generated";

export default dialexH3({ ...dialex });
```

```ts
// server/api/hello.get.ts
export default defineEventHandler((event) => {
  const dict = event.context.getDictionary("home");
  return {
    locale: event.context.locale,
    title: dict.title,
    subtitle: event.context.t("home.subtitle"),
  };
});
```

Middleware `event.context.locale`, `event.context.getDictionary(name)` ve `event.context.t` değerlerini doldurur ve `setHeader` `false` olmadıkça `Content-Language` başlığını ayarlar. Tüm [yerel ayar algılama seçenekleri](../guide/locale-detection.md#options) geçerlidir ve `custom`, h3 olayını alır.

::: warning Sürüm
h3 `>=1.8 <2` ile geliştirildi ve test edildi. h3 2.x farklı bir API'ye sahiptir ve henüz desteklenmiyor.
:::

## En iyi uygulamalar

- `dialex.generated.ts` içindeki `{ ...dialex }` değerini adaptöre geçirin. Sözlükleri ve yerel ayar yapılandırmasını taşır; böylece `defaultLocale`, `locales` ve `fallbacks` yalnızca bir kez, `dialex.config.ts` içinde yazılır.
- Nuxt ve Nitro'da ara katmanı `server/middleware/` içine koyun; böylece her istekte API rotalarından ve oluşturuculardan önce çalışır.
- Tek dizeler için `event.context.t("home.title")`, birden fazla anahtar gerektiğinde `event.context.getDictionary("home")` kullanın; böylece aramalar tek bir çözülmüş yerel ayarı paylaşır.

## Sorun giderme

- **`event.context.getDictionary` tanımsız**: ara katman dosyası `server/middleware/` içinde değil veya varsayılan bir işleyici dışa aktarmıyor.
- **h3 2.x desteklenmiyor**: adaptör h3 1.x'i (Nitro 2 ve Nuxt 3/4) hedefler. Çerçevenizin kurduğu h3 sürümünü kontrol edin.
- **`[dialex] Dictionary "x" not found`**: sözlük `dialex.generated.ts` içinde değil. `dx generate` çalıştırın ve `dialex.config.ts` içindeki `include` değerinin dosyayla eşleştiğini kontrol edin.
