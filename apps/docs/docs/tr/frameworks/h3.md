# h3 / Nitro

h3 1.x sunucuları için: Nitro 2 ile Nuxt sunucu rotaları ve middleware'i.

```ts
// server/middleware/i18n.ts (Nuxt / Nitro)
import { i18n } from "dialexjs/h3";
import dictionaries from "~/dialex.generated";

export default i18n({ defaultLocale: "en", locales: ["en", "tr"], dictionaries });
```

```ts
// server/api/hello.get.ts
export default defineEventHandler((event) => {
  const dict = event.context.getDictionary("home");
  return {
    locale: event.context.locale,
    title: dict.title,
    subtitle: event.context.t("home.subtitle"),
  };
});
```

Middleware `event.context.locale`, `event.context.getDictionary(name)` ve `event.context.t` değerlerini doldurur ve `setHeader` `false` olmadıkça `Content-Language` başlığını ayarlar. Tüm [yerel ayar algılama seçenekleri](../guide/locale-detection.md#options) geçerlidir ve `custom`, h3 olayını alır.

::: warning Sürüm
h3 `>=1.8 <2` ile geliştirildi ve test edildi. h3 2.x farklı bir API'ye sahiptir ve henüz desteklenmiyor.
:::
