# Glosario

Los términos que usa Dialex, en orden alfabético, con un enlace a donde se explica cada uno.

| Término                 | Significado                                                                                                                                                                                                                               |
| ----------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Adaptador**           | El punto de entrada `dialexjs/<framework>` que resuelve el locale de una petición y da a tu código `getDictionary` y `t`. Consulta [Adaptadores de servidor](../api/server-adapters.md)                                                   |
| **Análisis**            | Leer diccionarios, configuración y código fuente desde su árbol de sintaxis para encontrar problemas. Nunca ejecuta tu código. Lo comparten `dialex check`, el editor y el servidor de lenguaje                                           |
| **Argumento**           | Un valor con nombre en un mensaje ICU: `{name}`, `{count, plural, ...}`                                                                                                                                                                   |
| **Configuración**       | `dialex.config.ts`: `defaultLocale`, `locales`, `include`, `fallbacks`, `lazy`, `translate`... Consulta [Configuración](./configuration.md)                                                                                               |
| **Locale por defecto**  | El locale que se usa cuando una petición o un proveedor no decide otro, y con el que se comparan los demás locales. `defaultLocale` en la configuración                                                                                   |
| **Diccionario**         | Un objeto con nombre que asigna a cada locale su contenido. Se define con `defineDictionary` en un archivo `*.content.ts`. Consulta [Diccionarios](./dictionaries.md)                                                                     |
| **Diagnóstico**         | Un problema que informa Dialex, con código, gravedad y mensaje. Consulta [Referencia de diagnósticos](./diagnostics.md)                                                                                                                   |
| **Cadena de fallback**  | La lista ordenada de locales que se prueban para una clave: el locale, sus fallbacks explícitos, su idioma sin región y luego el locale por defecto. Consulta [Fallbacks](./fallbacks.md)                                                 |
| **Mensaje de función**  | Un valor de diccionario que es una función: `` (name: string) => `Hello, ${name}` ``. Tipado por TypeScript                                                                                                                               |
| **Archivo generado**    | `dialex.generated.ts` y `dialex-env.d.ts`, escritos por `dialex generate`. No los edites. Consulta [`dialex generate`](../cli/generate.md)                                                                                                |
| **Hidratación**         | Un framework de cliente que se engancha al HTML renderizado en el servidor. El primer render del cliente debe usar el locale del servidor (`initialLocale`) para coincidir                                                                |
| **Mensaje ICU**         | Una cadena con la sintaxis ICU MessageFormat, con argumentos, `plural`, `select`, números y fechas. Consulta [Mensajes ICU](./icu.md)                                                                                                     |
| **Clave**               | Un nombre dentro de un locale de un diccionario. Puede estar anidada: `nav.about`                                                                                                                                                         |
| **Ruta de clave**       | Un nombre de diccionario y una clave unidos con puntos: `home.nav.about`. Lo que pasas a `t()`. Consulta [Rutas de claves](./key-paths.md)                                                                                                |
| **Carga diferida**      | Cargar diccionarios bajo demanda en lugar de empaquetarlos todos, con `lazy: true` o `"locale"`. Consulta [Carga diferida](./lazy-loading.md)                                                                                             |
| **Hoja (leaf)**         | Un valor de un diccionario que no es un objeto: una cadena, una función u otro valor                                                                                                                                                      |
| **Locale**              | Una etiqueta de idioma como `en`, `tr` o `pt-BR`                                                                                                                                                                                          |
| **Archivo de bloqueo**  | `dialex.lock.json`: registra de qué texto de origen se hizo cada traducción, para notar un cambio posterior del origen. Consulta [Mantener las traducciones al día](../cli/translate.md#keeping-translations-in-sync)                     |
| **Paridad**             | Que cada locale de un diccionario tenga las mismas claves (y los mismos argumentos ICU). Lo comprueba `dialex check`                                                                                                                      |
| **Persistencia**        | Recordar la elección de locale del usuario en una cookie o en `localStorage`                                                                                                                                                              |
| **Categoría de plural** | Una de `zero`, `one`, `two`, `few`, `many`, `other`: las formas que distinguen las reglas de plural de un idioma (CLDR)                                                                                                                   |
| **Proveedor**           | Un componente o plugin de un framework de UI que guarda el locale activo, como `DialexProvider`                                                                                                                                           |
| **Registro**            | La interfaz `DictionaryRegistry` que `dialex-env.d.ts` rellena con los nombres y tipos de tus diccionarios. Consulta [Tipos](../api/types.md)                                                                                             |
| **Locale de origen**    | El locale desde el que se hizo una traducción, normalmente el locale por defecto. `translate.sourceLocale`                                                                                                                                |
| **Traducción obsoleta** | Una traducción cuyo texto de origen cambió después de traducirse, según el archivo de bloqueo                                                                                                                                             |
| **Análisis estático**   | Leer código sin ejecutarlo. Los diccionarios y configuraciones escritos con literales se pueden leer estáticamente; los spreads, claves calculadas e importaciones no. Consulta [Diccionarios](./dictionaries.md#what-the-tools-can-read) |
| **Marcador `[TODO]`**   | El prefijo que `dialex check --fix` pone a una cadena copiada para que sea fácil de encontrar y traducir                                                                                                                                  |
