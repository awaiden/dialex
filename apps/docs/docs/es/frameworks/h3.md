# h3 / Nitro

Para servidores h3 1.x: Nitro 2, y las rutas y el middleware de servidor de Nuxt.

```ts
// server/middleware/i18n.ts (Nuxt / Nitro)
import { i18n } from "dialexjs/h3";
import dictionaries from "~/i18n.generated";

export default i18n({ defaultLocale: "en", locales: ["en", "tr"], dictionaries });
```

```ts
// server/api/hello.get.ts
export default defineEventHandler((event) => {
  const dict = event.context.getDictionary("home");
  return {
    locale: event.context.locale,
    title: dict.title,
    subtitle: event.context.t("home.subtitle"),
  };
});
```

El middleware rellena `event.context.locale`, `event.context.getDictionary(name)` y `event.context.t`, y establece `Content-Language` a menos que `setHeader` sea `false`. Se aplican todas las [opciones de detección de locale](../guide/locale-detection.md#options), y `custom` recibe el evento de h3.

::: warning Versión
Desarrollado y probado con h3 `>=1.8 <2`. h3 2.x tiene una API distinta y todavía no es compatible.
:::
