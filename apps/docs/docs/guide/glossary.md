# Glossary

The terms Dialex uses, in alphabetical order, with a link to where each is explained.

| Term                     | Meaning                                                                                                                                                                                                          |
| ------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Adapter**              | The `dialexjs/<framework>` entry point that resolves a request's locale and gives your code `getDictionary` and `t`. See [Server adapters](../api/server-adapters.md)                                            |
| **Analysis**             | Reading dictionaries, config and source code from their syntax tree to find problems. It never runs your code. Shared by `dialex check`, the editor and the language server                                      |
| **Argument**             | A named value in an ICU message: `{name}`, `{count, plural, ...}`                                                                                                                                                |
| **Config**               | `dialex.config.ts`: `defaultLocale`, `locales`, `include`, `fallbacks`, `lazy`, `translate`... See [Configuration](./configuration.md)                                                                           |
| **Default locale**       | The locale used when a request or a provider decides nothing else, and the one other locales are compared with. `defaultLocale` in the config                                                                    |
| **Dictionary**           | A named object that maps each locale to its content. Defined with `defineDictionary` in a `*.content.ts` file. See [Dictionaries](./dictionaries.md)                                                             |
| **Diagnostic**           | A problem Dialex reports, with a code, a severity and a message. See [Diagnostics reference](./diagnostics.md)                                                                                                   |
| **Fallback chain**       | The ordered list of locales tried for a key: the locale, its explicit fallbacks, its language without region, then the default locale. See [Fallbacks](./fallbacks.md)                                           |
| **Function message**     | A dictionary value that is a function: `` (name: string) => `Hello, ${name}` ``. Typed by TypeScript                                                                                                             |
| **Generated file**       | `dialex.generated.ts` and `dialex-env.d.ts`, written by `dialex generate`. Never edit them. See [`dialex generate`](../cli/generate.md)                                                                          |
| **Hydration**            | A client framework attaching to server-rendered HTML. The first client render must use the server's locale (`initialLocale`) to match                                                                            |
| **ICU message**          | A string in the ICU MessageFormat syntax, with arguments, `plural`, `select`, numbers and dates. See [ICU Messages](./icu.md)                                                                                    |
| **Key**                  | A name inside one locale of a dictionary. May be nested: `nav.about`                                                                                                                                             |
| **Key path**             | A dictionary name and a key joined with dots: `home.nav.about`. What you pass to `t()`. See [Key Paths](./key-paths.md)                                                                                          |
| **Lazy loading**         | Loading dictionaries on demand instead of bundling them all, with `lazy: true` or `"locale"`. See [Lazy Loading](./lazy-loading.md)                                                                              |
| **Leaf**                 | A value in a dictionary that is not an object: a string, a function or another value                                                                                                                             |
| **Locale**               | A language tag such as `en`, `tr` or `pt-BR`                                                                                                                                                                     |
| **Lock file**            | `dialex.lock.json`: records which source text each translation was made from, so a later change of the source is noticed. See [Keeping translations in sync](../cli/translate.md#keeping-translations-in-sync)   |
| **Parity**               | Every locale of a dictionary having the same keys (and the same ICU arguments). Checked by `dialex check`                                                                                                        |
| **Persist**              | Remembering the user's locale choice in a cookie or `localStorage`                                                                                                                                               |
| **Plural category**      | One of `zero`, `one`, `two`, `few`, `many`, `other`: the forms a language's plural rules distinguish (CLDR)                                                                                                      |
| **Provider**             | A component or plugin of a UI framework that holds the active locale, such as `DialexProvider`                                                                                                                   |
| **Registry**             | The `DictionaryRegistry` interface that `dialex-env.d.ts` fills with your dictionary names and types. See [Types](../api/types.md)                                                                               |
| **Source locale**        | The locale a translation was made from, usually the default locale. `translate.sourceLocale`                                                                                                                     |
| **Stale translation**    | A translation whose source text changed after it was translated, according to the lock file                                                                                                                      |
| **Static analysis**      | Reading code without running it. Dictionaries and configs written with literals can be read statically; spreads, computed keys and imports cannot. See [Dictionaries](./dictionaries.md#what-the-tools-can-read) |
| **`[TODO]` placeholder** | The prefix `dialex check --fix` puts on a copied string so it is easy to find and translate                                                                                                                      |
