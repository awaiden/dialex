# h3 / Nitro

适用于 h3 1.x 服务器：Nitro 2，以及 Nuxt 的服务端路由和中间件。

```ts
// server/middleware/dialex.ts (Nuxt / Nitro)
import { dialexH3 } from "dialexjs/h3";

import { dialex } from "~/dialex.generated";

export default dialexH3({ ...dialex });
```

```ts
// server/api/hello.get.ts
export default defineEventHandler((event) => {
  const dict = event.context.getDictionary("home");
  return {
    locale: event.context.locale,
    title: dict.title,
    subtitle: event.context.t("home.subtitle"),
  };
});
```

该中间件会填充 `event.context.locale`、`event.context.getDictionary(name)` 和 `event.context.t`，并在 `setHeader` 不为 `false` 时设置 `Content-Language`。所有 [locale 检测选项](../guide/locale-detection.md#options)均适用，`custom` 会接收到 h3 事件。

::: warning 版本
基于 h3 `>=1.8 <2` 构建和测试。h3 2.x 的 API 不同，目前尚不支持。
:::

## 最佳实践

- 把 `dialex.generated.ts` 中的 `{ ...dialex }` 传给适配器。它同时带有词典和 locale 配置，因此 `defaultLocale`、`locales` 和 `fallbacks` 只需在 `dialex.config.ts` 中写一次。
- 在 Nuxt 和 Nitro 中把中间件放在 `server/middleware/`，使它在每个请求上先于 API 路由和渲染器运行。
- 单个字符串用 `event.context.t("home.title")`，需要多个键时用 `event.context.getDictionary("home")`，让这些查找共享同一个已解析的 locale。

## 故障排除

- **`event.context.getDictionary` 是 undefined**：中间件文件不在 `server/middleware/` 中，或者没有导出默认处理函数。
- **不支持 h3 2.x**：该适配器面向 h3 1.x（Nitro 2 和 Nuxt 3/4）。请检查你的框架安装的 h3 版本。
- **`[dialex] Dictionary "x" not found`**：该词典不在 `dialex.generated.ts` 中。运行 `dx generate`，并检查 `dialex.config.ts` 中的 `include` 是否匹配该文件。
