  - title: Durchgängige Typsicherheit
    details: Autovervollständigung für Wörterbuchnamen, Schlüssel, Locales und typisierte Aufrufe von t("dictionary.key.path").
  - title: Eine API, jedes Framework
    details: Next.js, React, Vue und Nuxt, SvelteKit, Astro, Express, Fastify, Koa, Hono, Elysia, NestJS, h3 und jede Fetch-API-Laufzeit.
  - title: Plurale, Formatierung und Fallbacks
    details: Typisierte Intl-Helfer für Plurale, Zahlen, Datumsangaben und Listen sowie Locale-Fallback-Ketten.
  - title: Routing und SEO
    details: URLs mit Locale-Präfix, eine Next.js-Middleware samt Link, hreflang-Alternativen und Sitemaps.
  - title: Eine CLI für den gesamten Workflow
    details: Projektgerüst erstellen, Code generieren, Nutzung und Parität prüfen, für Übersetzer exportieren und Lücken per maschineller Übersetzung füllen.
