# Glossar

Die Begriffe, die Dialex verwendet, in alphabetischer Reihenfolge, mit einem Link dorthin, wo sie erklärt werden.

| Begriff                   | Bedeutung                                                                                                                                                                                                                                  |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Adapter**               | Der Einstiegspunkt `dialexjs/<framework>`, der die Locale eines Requests auflöst und deinem Code `getDictionary` und `t` gibt. Siehe [Server-Adapter](../api/server-adapters.md)                                                           |
| **Analyse**               | Das Lesen von Wörterbüchern, Konfiguration und Quellcode aus ihrem Syntaxbaum, um Probleme zu finden. Sie führt deinen Code nie aus. Gemeinsam genutzt von `dialex check`, Editor und Language Server                                      |
| **Argument**              | Ein benannter Wert in einer ICU-Nachricht: `{name}`, `{count, plural, ...}`                                                                                                                                                                |
| **Konfiguration**         | `dialex.config.ts`: `defaultLocale`, `locales`, `include`, `fallbacks`, `lazy`, `translate`... Siehe [Konfiguration](./configuration.md)                                                                                                   |
| **Standard-Locale**       | Die Locale, die verwendet wird, wenn ein Request oder Provider nichts anderes bestimmt, und die, mit der andere Locales verglichen werden. `defaultLocale` in der Konfiguration                                                            |
| **Wörterbuch**            | Ein benanntes Objekt, das jede Locale auf ihren Inhalt abbildet. Mit `defineDictionary` in einer `*.content.ts`-Datei definiert. Siehe [Wörterbücher](./dictionaries.md)                                                                   |
| **Diagnose**              | Ein von Dialex gemeldetes Problem mit Code, Schweregrad und Meldung. Siehe [Diagnose-Referenz](./diagnostics.md)                                                                                                                           |
| **Fallback-Kette**        | Die geordnete Liste der für einen Schlüssel versuchten Locales: die Locale, ihre expliziten Fallbacks, ihre Sprache ohne Region, dann die Standard-Locale. Siehe [Fallbacks](./fallbacks.md)                                               |
| **Funktionsnachricht**    | Ein Wörterbuchwert, der eine Funktion ist: `` (name: string) => `Hello, ${name}` ``. Von TypeScript typisiert                                                                                                                              |
| **Generierte Datei**      | `dialex.generated.ts` und `dialex-env.d.ts`, geschrieben von `dialex generate`. Nie bearbeiten. Siehe [`dialex generate`](../cli/generate.md)                                                                                              |
| **Hydration**             | Ein Client-Framework, das sich an servergerendertes HTML anhängt. Das erste Client-Rendering muss die Locale des Servers (`initialLocale`) verwenden, damit es passt                                                                       |
| **ICU-Nachricht**         | Ein String in der ICU-MessageFormat-Syntax, mit Argumenten, `plural`, `select`, Zahlen und Datumswerten. Siehe [ICU-Nachrichten](./icu.md)                                                                                                 |
| **Schlüssel**             | Ein Name innerhalb einer Locale eines Wörterbuchs. Kann verschachtelt sein: `nav.about`                                                                                                                                                    |
| **Schlüsselpfad**         | Ein Wörterbuchname und ein Schlüssel, mit Punkten verbunden: `home.nav.about`. Was du `t()` übergibst. Siehe [Schlüsselpfade](./key-paths.md)                                                                                              |
| **Lazy Loading**          | Wörterbücher bei Bedarf laden, statt sie alle zu bündeln, mit `lazy: true` oder `"locale"`. Siehe [Lazy Loading](./lazy-loading.md)                                                                                                        |
| **Blatt (Leaf)**          | Ein Wert in einem Wörterbuch, der kein Objekt ist: ein String, eine Funktion oder ein anderer Wert                                                                                                                                         |
| **Locale**                | Ein Sprach-Tag wie `en`, `tr` oder `pt-BR`                                                                                                                                                                                                 |
| **Lock-Datei**            | `dialex.lock.json`: zeichnet auf, aus welchem Ausgangstext jede Übersetzung entstand, damit eine spätere Änderung der Quelle bemerkt wird. Siehe [Übersetzungen aktuell halten](../cli/translate.md#keeping-translations-in-sync)          |
| **Parität**               | Jede Locale eines Wörterbuchs hat dieselben Schlüssel (und dieselben ICU-Argumente). Von `dialex check` geprüft                                                                                                                            |
| **Persist**               | Die Locale-Wahl des Nutzers in einem Cookie oder `localStorage` merken                                                                                                                                                                     |
| **Pluralkategorie**       | Eine von `zero`, `one`, `two`, `few`, `many`, `other`: die Formen, die die Pluralregeln einer Sprache unterscheiden (CLDR)                                                                                                                 |
| **Provider**              | Eine Komponente oder ein Plugin eines UI-Frameworks, das die aktive Locale hält, etwa `DialexProvider`                                                                                                                                     |
| **Registry**              | Das Interface `DictionaryRegistry`, das `dialex-env.d.ts` mit deinen Wörterbuchnamen und -typen füllt. Siehe [Typen](../api/types.md)                                                                                                      |
| **Ausgangs-Locale**       | Die Locale, aus der eine Übersetzung entstand, meist die Standard-Locale. `translate.sourceLocale`                                                                                                                                         |
| **Veraltete Übersetzung** | Eine Übersetzung, deren Ausgangstext sich nach der Übersetzung geändert hat, laut Lock-Datei                                                                                                                                               |
| **Statische Analyse**     | Code lesen, ohne ihn auszuführen. Mit Literalen geschriebene Wörterbücher und Konfigurationen lassen sich statisch lesen; Spreads, berechnete Schlüssel und Importe nicht. Siehe [Wörterbücher](./dictionaries.md#what-the-tools-can-read) |
| **`[TODO]`-Platzhalter**  | Das Präfix, das `dialex check --fix` einem kopierten String voranstellt, damit er leicht zu finden und zu übersetzen ist                                                                                                                   |
