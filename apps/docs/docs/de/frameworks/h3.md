# h3 / Nitro

Für h3-1.x-Server: Nitro 2 sowie Nuxt-Serverrouten und -Middleware.

```ts
// server/middleware/i18n.ts (Nuxt / Nitro)
import { i18n } from "dialex/h3";
import dictionaries from "~/i18n.generated";

export default i18n({ defaultLocale: "en", locales: ["en", "tr"], dictionaries });
```

```ts
// server/api/hello.get.ts
export default defineEventHandler((event) => {
  const dict = event.context.getDictionary("home");
  return {
    locale: event.context.locale,
    title: dict.title,
    subtitle: event.context.t("home.subtitle"),
  };
});
```

Die Middleware füllt `event.context.locale`, `event.context.getDictionary(name)` und `event.context.t` und setzt `Content-Language`, sofern `setHeader` nicht `false` ist. Alle [Optionen der Locale-Erkennung](../guide/locale-detection.md#options) gelten, und `custom` erhält das h3-Event.

::: warning Version
Gebaut und getestet mit h3 `>=1.8 <2`. h3 2.x hat eine andere API und wird noch nicht unterstützt.
:::
