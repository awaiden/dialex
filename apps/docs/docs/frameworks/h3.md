# h3 / Nitro

For h3 1.x servers: Nitro 2, and Nuxt server routes and middleware.

```ts
// server/middleware/dialex.ts (Nuxt / Nitro)
import { dialexH3 } from "dialexjs/h3";

import { dialex } from "~/dialex.generated";

export default dialexH3({ ...dialex });
```

```ts
// server/api/hello.get.ts
export default defineEventHandler((event) => {
  const dict = event.context.getDictionary("home");
  return {
    locale: event.context.locale,
    title: dict.title,
    subtitle: event.context.t("home.subtitle"),
  };
});
```

The middleware fills `event.context.locale`, `event.context.getDictionary(name)` and `event.context.t`, and sets `Content-Language` unless `setHeader` is `false`. All [locale detection options](../guide/locale-detection.md#options) apply, and `custom` receives the h3 event.

::: warning Version
Built and tested against h3 `>=1.8 <2`. h3 2.x has a different API and is not supported yet.
:::

## Install

Install the framework package you already use together with Dialex, then compile the dictionaries:

```bash
npm install dialexjs h3
npm install -D @dialexjs/cli
npx dialex generate
```

## Options

The adapter takes the [locale detection options](../guide/locale-detection.md), `dictionaries` and `setHeader`. Every option, adapter by adapter, is on [Server adapters](../api/server-adapters.md).

## TypeScript

`dialex generate` writes `dialex-env.d.ts`. With it included in `tsconfig.json` (and `moduleResolution` set to `"bundler"` or `"nodenext"`), `event.context.getDictionary("home")` autocompletes the dictionary names, types the content, and `locale` is the union of your configured locales.

## Best practices

- Pass `{ ...dialex }` from `dialex.generated.ts` to the adapter. It carries the dictionaries and the locale config, so `defaultLocale`, `locales` and `fallbacks` are written once, in `dialex.config.ts`.
- In Nuxt and Nitro put the middleware in `server/middleware/`, so it runs for every request before API routes and renderers.
- Use `event.context.t("home.title")` for single strings and `event.context.getDictionary("home")` when you need several keys, so the lookups share one resolved locale.

## Troubleshooting

- **`event.context.getDictionary` is undefined**: the middleware file is not in `server/middleware/`, or it does not export a default handler.
- **h3 2.x is not supported**: the adapter targets h3 1.x (Nitro 2 and Nuxt 3/4). Check the h3 version your framework installs.
- **`[dialex] Dictionary "x" not found`**: the dictionary is not in `dialex.generated.ts`. Run `dx generate` and check that `include` in `dialex.config.ts` matches the file.
