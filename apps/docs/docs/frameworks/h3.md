# h3 / Nitro

For h3 1.x servers: Nitro 2, and Nuxt server routes and middleware.

```ts
// server/middleware/i18n.ts (Nuxt / Nitro)
import { i18n } from "dialexjs/h3";
import dictionaries from "~/dialex.generated";

export default i18n({ defaultLocale: "en", locales: ["en", "tr"], dictionaries });
```

```ts
// server/api/hello.get.ts
export default defineEventHandler((event) => {
  const dict = event.context.getDictionary("home");
  return {
    locale: event.context.locale,
    title: dict.title,
    subtitle: event.context.t("home.subtitle"),
  };
});
```

The middleware fills `event.context.locale`, `event.context.getDictionary(name)` and `event.context.t`, and sets `Content-Language` unless `setHeader` is `false`. All [locale detection options](../guide/locale-detection.md#options) apply, and `custom` receives the h3 event.

::: warning Version
Built and tested against h3 `>=1.8 <2`. h3 2.x has a different API and is not supported yet.
:::
